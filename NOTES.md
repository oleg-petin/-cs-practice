Рабочая папка - Папка с файлами проекта на моём компьютере, где я их редактирую.
Git видит изменения в ней, но пока ничего не сохраняет

Индекс - Промежуточная зона между рабочей папкой и историей. Командой
`git add` выбираю, какие изменения попадут в следующий коммит

Коммит - Снимок проекта в истории с сообщением и автором

Git и GitHub различаются следующим: Git - это программа для контроля версий, которая работает локально на компьютере: хранит историю изменений, комиты и ветки. GitHub - это онлайн сервис, где хранятся Git-репозитории в облаке

git diff - сравнивает рабочую директорию с индексом. Показывает изменения, которые вы сделали, но ещё не добавили через git add.
git diff --staged - сравнивает индекс с последним коммитом (HEAD). Показывает то, что уже добавлено через git add и попадёт в следующий коммит
