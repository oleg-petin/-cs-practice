git diff показывает разницу между состояниями: рабочая папка и индекс, индекс и последний коммит, два коммита или две ветки. Коммит для него не обязателен, так что это способ посмотреть ещё не закоммиченные правки.

git show <коммит> показывает один конкретный коммит: автора, дату, сообщение и его изменения. Также умеет показывать файл в нужной версии: git show HEAD~3:path/file.

git log показывает список коммитов, то есть историю. Изменения в нём видны только с -p.

git log -S"текст" находит коммиты, в которых количество вхождений этой строки изменилось, то есть где она была добавлена или удалена. Отвечает на вопрос «когда появилась (или пропала) эта функция или переменная». Для поиска по регулярке есть -G. Обычно пишут git log -S"имя" -p, чтобы сразу увидеть правки.

git blame файл для каждой строки текущего файла показывает, какой коммит и кто изменил её последним. Отвечает на вопрос «кто и когда в последний раз трогал эту строку».
